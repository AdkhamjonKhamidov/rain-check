# Rain check

The one stop for all the weather info you need

# Features
*   Simple interface to view weather, toggle units

# Installation

``` bash
# Clon the repo 
git clone git@github.com:AdkhamjonKhamidov/rain-check.git

cd rain-check

npm install
```
## Configuration
Set your API keys for weather api and uv api using the .env.example as the structure.
https://openweathermap.org/api/one-call-4?collection=one_call_api
https://www.openuv.io

## Usage 
node index.js
runs on http://localhost:3000
